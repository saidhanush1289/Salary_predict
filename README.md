# Salary Prediction Model

A machine learning project that predicts employee salaries based on key career and demographic features such as years of experience, job role, education level, and location.

## 📌 Project Overview
Understanding salary trends helps both job seekers and employers make informed decisions. This project explores a salary dataset, performs exploratory data analysis (EDA) and feature engineering, and trains regression models to accurately estimate expected compensation.

## 🛠️ Technologies & Libraries Used
* **Language:** Python 3.x
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn *(add XGBoost, LightGBM, etc., if used)*
* **Environment:** Jupyter Notebook / VS Code *(adjust as needed)*
